## 学习总结

1. 我学会了使用 clone 克隆仓库，使用 add 和 commit 保存本地修改，
   再通过 push 将提交上传到 GitHub。
2. 我学会了创建和切换分支，以及合并分支时手动解决冲突。
   解决冲突后，需要删除冲突标记、保存文件并重新提交。
3. 我使用预训练 ResNet-18 对 MNIST 测试集进行了推理，
   将灰度图片转为 RGB，并通过预处理器调整到 224×224。
4. 测试集共 10000 张图片，直接比较类别编号得到 1 个匹配，
   比例为 0.0001，即 0.01%。由于 ImageNet 与 MNIST 的标签
   含义不同，这个结果不代表有效的数字识别准确率。
5. 我学会了通过 detached HEAD 查看历史提交，再切换回 main。
